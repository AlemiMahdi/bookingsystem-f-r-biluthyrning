10. Tillgänglighet (WCAG)

Applikationen uppfyller WCAG AA på alla sidor och WCAG AAA på inloggningssidan. Stilar i css/accessibility.css.

WCAG AA — Alla sidor

  • ✅ Skip-link för tangentbordsnavigering
  • ✅ Fokusindikatorer på alla interaktiva element
  • ✅ ARIA-attribut på modal, nav, main
  • ✅ ESC-tangent stänger modal
  • ✅ role="alert" på felmeddelanden
  • ✅ aria-live="polite" på main content
  • ✅ Minst 4.5:1 färgkontrast

WCAG AAA — Inloggningssidan

  • ✅ 7:1 färgkontrast (svart på vit)
  • ✅ .sr-only för screen readers
  • ✅ aria-required på obligatoriska fält
  • ✅ aria-describedby för hjälptext
  • ✅ prefers-reduced-motion stöd
  • ✅ prefers-contrast: high stöd
  • ✅ Fokus sätts automatiskt i modal

Fokusindikator — outline: 3px solid #d4af37
